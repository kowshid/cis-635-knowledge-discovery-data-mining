# CIS 635 - Knowledge Discovery and Data Mining

This repository contains course contents, and assignments for **CIS 635: Knowledge Discovery and Data Mining**.

## Course Overview

This course teaches students to extract knowledge from data by solving real-world analytical problems, emphasizing the
full data mining process, from data preparation to actionable insight, and developing sound judgment in applying data
mining and knowledge discovery methods across domains such as healthcare, life sciences, business, and other applied
areas. Particular emphasis is placed on applications in bioinformatics and health-related data: students gain hands-on
experience with biological and biomedical databases, dynamic programming for sequence alignment and similarity search
(e.g., BLAST), hidden Markov models for sequence and structure analysis, and clustering and classification methods for
gene-expression data. Students also build practical skills in Python-based data analysis, data preparation and
visualization, predictive modeling, model evaluation, clustering, dimensionality reduction, association analysis, and
neural networks, and gain experience formulating queries against relational and nonrelational databases while completing
end-to-end knowledge discovery tasks involving real-world datasets.
